# 页面原型预览

直接用浏览器打开HTML文件，无需启动后端。

- `index.html`：教材市场，可搜索、筛选并进入详情。
- `detail.html?id=1`：按编号查看资料详情。
- `publish.html`：新建资料表单。
- `publish.html?edit=1`：回填第1条演示资料，体验编辑表单；免费赠送示例可使用 `?edit=3`。
- `my-listings.html`：我的发布，状态筛选、预订、取消预订、售出／送出、上下架和操作记录。
- `login.html`、`register.html`：演示登录与注册表单；密码不保存，登录只记录演示状态。
- `profile.html`：默认联系方式和密码修改表单预览。
- `admin-listings.html`：管理员下架、解除限制和操作记录。
- `admin-reports.html`：处理或驳回举报，处理时下架相关资料。
- `admin-options.html`：专业与考试标签新增、重命名、启用和停用。

发布页右上角提供编辑模式入口，首页与详情页的“发布资料”入口均跳转到该表单。

## 表单行为

支持图片选择、预览、移除和设置封面，出售／免费赠送切换，多组专业学期、课程选填和考试标签多选。提交时校验必填项、价格、图片数量和重复适用范围，随后显示效果预览。

本原型没有真实登录、文件上传或数据库服务。编辑模式只用于演示，不表示具备修改其他用户资料的权限。预览不改变首页数据，不保存联系方式或图片；刷新或离开页面会丢失输入。请使用虚拟联系方式体验。

## 完整流程演示

1. 从首页进入“我的发布”，对出售资料标记已预订；返回市场，确认它已退出可获取列表。
2. 取消预订后重新出现；标记已售出／已送出后不可编辑或重新上架，公开详情不再提供正文及联系方式。
3. 打开详情，点击联系入口体验演示登录。登录允许任意合法格式的虚拟账号与密码，不校验真实凭据；注册仅展示校验结果，不创建账号。
4. 登录后可以提交演示举报，在“管理后台演示 → 举报处理”中处理或驳回。管理员下架会阻止发布者自行恢复。
5. 停用专业或标签后，新发布的选项中不再出现该值，历史条目的显示和筛选仍保留。
6. 点击个人中心或后台的“重置演示数据”，恢复初始状态。

演示状态、管理选项和举报保存在 `sessionStorage` 中，通常在同一标签页跨页面访问时保留。账号密码、联系方式、上传图片不进入该存储。浏览器限制 `file://` 存储时跨页演示可能不连续，可在该目录运行 `python3 -m http.server 8000`，通过 `http://localhost:8000` 预览。

所有预置条目在“我的发布”中视为演示账号持有；后台可直接访问是为了评审原型，不能作为正式权限实现。发布表单仍只预览，不新增真实条目。状态操作是本地模拟，Java后端尚未实现。

前端图片检查不能代替正式后端的文件类型、大小、权限和业务校验。生产实现应由Java服务端执行对应规则。
