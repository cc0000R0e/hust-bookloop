# 页面原型预览

直接用浏览器打开HTML文件，无需启动后端。

- `index.html`：教材市场，可搜索、筛选并进入详情。
- `detail.html?id=1`：按编号查看资料详情。
- `publish.html`：新建资料表单。
- `publish.html?edit=1`：回填第1条演示资料，体验编辑表单；免费赠送示例可使用 `?edit=3`。

发布页右上角提供编辑模式入口，首页与详情页的“发布资料”入口均跳转到该表单。

## 表单行为

支持图片选择、预览、移除和设置封面，出售／免费赠送切换，多组专业学期、课程选填和考试标签多选。提交时校验必填项、价格、图片数量和重复适用范围，随后显示效果预览。

本原型没有真实登录、文件上传或数据库服务。编辑模式只用于演示，不表示具备修改其他用户资料的权限。预览不改变首页数据，不保存联系方式或图片；刷新或离开页面会丢失输入。请使用虚拟联系方式体验。

前端图片检查不能代替正式后端的文件类型、大小、权限和业务校验。生产实现应由Java服务端执行对应规则。
